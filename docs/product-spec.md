# Focusday 최종 제품 명세

## 목적과 범위

생각난 일을 빠르게 담고 오늘 실행할 일만 고르는, 계정 없는 개인용 로컬 앱. 주 사용자는 관리 체계·설정을 오래 유지하고 싶지 않은 개인이라는 **설계 가설**이다.

React + TypeScript + Vite + CSS + localStorage. 최상위 탐색은 오늘/전체. 로그인, 서버, DB, 클라우드 동기화, 협업·공유, 캘린더, 시간별 일정, 반복·알림, 하위 작업, 메모·첨부, 습관, 포모도로, 게임화, 앱 내부 AI, 음성/NLP, 드래그, 대량 편집, 테마·다크 모드, PWA는 제외한다.

## 데이터

`AppData = { version: 1, tasks: Task[] }`, 저장 키 `focusday:v1`.

| 필드                  | 규칙                                                       |
| --------------------- | ---------------------------------------------------------- |
| id                    | 고유 문자열. 새 항목은 crypto.randomUUID                   |
| title                 | trim, 필수, 최대 200자(입력과 JavaScript 문자열 길이 기준) |
| createdAt / updatedAt | ISO UTC timestamp                                          |
| completedAt           | ISO UTC timestamp 또는 null                                |
| dueDate / focusDate   | 유효한 로컬 달력 날짜 YYYY-MM-DD 또는 null                 |
| priority              | none / low / medium / high → 없음 / 낮음 / 보통 / 높음     |
| category              | 단일 선택적 문자열, trim 후 최대 24자 또는 null            |
| isDemo                | boolean, 직접 만든 항목은 항상 false                       |

## 생성·보기·검색

오늘에서 생성하면 focusDate=오늘, 전체에서 생성하면 null. dueDate=null, priority=none, category=null, completedAt=null. 성공 후 입력을 비우고 포커스를 유지한다. 공백만 입력하면 오류를 안내한다. IME 조합 중 Enter, keyCode 229와 조합 종료 직후 같은 Enter는 제출하지 않는다.

오늘의 미완료 포함 조건은 `focusDate === today || (유효한 dueDate !== null && dueDate <= today)`이다. 기한 초과는 별도 섹션에 먼저 표시하고 나머지 오늘 항목과 중복시키지 않는다. 전체에는 모든 미완료가 있다. 완료는 전체의 접을 수 있는 영역에 제공한다.

검색은 현재 보기의 제목·분류에서 대소문자를 구분하지 않는 부분 문자열 검색이다. 전체에서는 완료도 포함하고 검색 중 완료 영역을 펼친다. 탐색 메뉴 수는 검색과 무관한 미완료 수, 검색 결과 수는 현재 보기의 검색 일치 수다.

## 정렬

- 오늘 기한 초과: 오래 지난 기한 → 높은 우선순위 → 먼저 생성 → id.
- 오늘 나머지: 높은 우선순위 → 먼저 생성 → id.
- 전체: 오늘/기한 초과 → 미래 기한 → 나머지. 각 그룹 안은 높은 우선순위 → 먼저 생성 → id.
- 완료: 최근 완료 → id. id는 동률의 안정적인 기준이다.

## 오늘 선택과 기한

오늘 추가/제거는 focusDate만 변경한다. 기한이 오늘/과거이면 집중을 해제해도 오늘에 남는다. “기한 때문에 오늘에도 표시됩니다.” 안내와 기한 편집 버튼을 제공한다. 편집기에서도 원인을 알려준다.

getFullYear/getMonth/getDate로 오늘을 구한다. 날짜 더하기는 로컬 달력의 setDate로 처리하며 시간은 정오로 설정한다. 날짜 간 차이는 달력 성분으로 계산해 DST의 23/25시간과 분리한다. 자정 타이머, window focus, visibilitychange에서 오늘과 다음 자정 타이머를 갱신한다. 지난 focusDate는 오늘에서 빠지지만 전체의 항목은 삭제하지 않는다.

## 편집·완료·복구

동일 편집기가 데스크톱 우측 모달 drawer, 모바일 bottom sheet로 열린다. 제목·오늘 집중·기한 설정/해제·우선순위·분류·보조 삭제를 제공한다. 저장만 적용하며 취소/Escape는 초안을 버린다. 빈 제목과 잘못된 날짜는 저장을 막는다.

native dialog와 명시적인 Tab 경계 유지, 최초 제목 포커스, 닫힌 후 호출 지점으로 복귀를 제공한다. 행이 사라지면 인접 항목 또는 입력창으로 포커스를 옮긴다. 모바일 편집기는 visualViewport 크기 변경을 반영한다.

완료는 completedAt을 기록한다. 전체 완료 영역에서 복원할 수 있다. 완료/삭제는 최근 한 건만 8초 실행 취소한다. hover와 키보드 포커스 동안 남은 시간을 멈추며 새 완료/삭제는 이전 알림을 교체한다. 토큰과 component key로 이전 타이머를 격리한다. 삭제 취소는 원래 Task 전체를, 완료 취소는 해당 항목의 완료 여부만 복원해 다른 속성 변경을 유지한다. 예시 데이터 제거는 예시용 일괄 관리이므로 삭제 취소 대상이 아니며 표시 중인 복구 정보도 해제한다.

## 저장·복구 상태

- 초기 load는 읽기만 수행한다. 기본 빈 값의 자동 저장 effect는 없다.
- 접근/읽기 실패: 자동 쓰기 차단, 다시 읽기. 성공 시 기존 항목과 메모리 항목을 id로 합친다.
- JSON/스키마/버전 오류: 원본 보존, 다운로드, 별도 명시적 초기화 확인.
- 쓰기 실패: 메모리 변경은 유지, 지속 경고·저장 재시도. 실제 다음 쓰기 성공 때만 실패 상태를 해제한다.
- 저장됨은 setItem 성공 후에만 표시한다. 초기 정상 데이터 읽기는 ‘로컬 데이터 불러옴’으로 표시한다.
- 초기화는 손상 원본을 현재 탭 목록으로 교체한다. setItem 실패 시 원본을 유지한다.

## 선택형 예시·빈 상태

현재 날짜에 맞춘 예시 5개는 사용자가 선택한 때만 추가한다. 기존 예시가 하나라도 있으면 중복 추가하지 않는다. 예시 제거는 isDemo=true만 제거하고 직접 작성한 항목을 보존한다.

첫 빈 화면, 오늘만 빈 화면, 전체 미완료 없음, 검색 결과 없음, 읽기/쓰기 오류를 별도로 안내한다. 검색 지우기, 첫 입력, 전체 보기, 예시, 재시도 등 다음 행동을 제공한다.

## 접근성과 시각 기준

semantic HTML, 이름 있는 native 입력/버튼/체크박스, 명확한 focus ring, status/alert, 텍스트로 기한·우선순위, reduced-motion을 사용한다. 핵심 터치 영역은 44px 이상을 목표로 한다. N 새 입력, / 검색은 일반 입력·IME·조합키·편집/확인 모달에서 가로채지 않는다. 일반 텍스트 대비와 실제 검증 범위는 [검증 기록](validation.md)에 있다. 전체 WCAG 준수 판정은 하지 않았다.

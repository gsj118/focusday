# v1.1 사용자 실행 요청

아래는 첨부 명세를 실행하도록 사용자가 요청한 메시지다. [첨부 개발 명세](04-v1.1-implementation.md)는 별도로 원문 보존했다. in-app browser의 ambient UI 상태는 사용자 지시로 간주하지 않았다.

> 현재 Focusday를 첨부한 `Focusday_v1_1_Codex_Prompt.md`에 따라 v1.1.0으로 실제 업데이트해 주세요.
> 첨부 파일은 실행할 개발 명세입니다. 현재 작업 폴더의 v1.0 코드와 데이터를 보존하면서 오늘 계획하기, 어제 미완료 이어가기, JSON 백업·복원과 관련 UX 개선을 구현해 주세요.
> 계획만 제시하고 멈추지 말고 구현 → 실제 검증 → 결함 수정 → 재검증 → 문서화 → Git 커밋·태그 → GitHub 반영·배포 확인까지 진행해 주세요. 기존 핵심 기능의 회귀 여부를 확인하고, 변경 전후와 실제 검증 결과를 기록해 주세요.
> 이 메시지는 개발을 시작하라는 명시적인 요청입니다. 지금 현재 프로젝트를 확인하고 업데이트를 시작해 주세요.

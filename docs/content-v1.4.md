| 종류/시점 | 문구                                       |
| --------- | ------------------------------------------ |
| calm/1    | 첫 한 가지를 마쳤어요. 작은 진전입니다.    |
| calm/3    | 오늘 세 가지를 마쳤어요. 잠깐 돌아보세요.  |
| humor/1   | 첫 체크, 목록에 작은 빈자리가 생겼네요.    |
| humor/3   | 오늘 체크 세 칸. 목록이 조금 가벼워졌네요. |

3개를 언급하는 문구는 실제3개 적용과 현재 날짜/수 일치를 확인한 toast에서만 표시한다. 첫 완료의 의미는 해당 로컬 날짜의 첫 실제 완료 시점이며 반복 praise/소급 축하를 하지 않는다. 점수·레벨·연속일·실패 표현 없음. id/종류/최소 수/중복·날짜 왕복과 전환은 단위·브라우저 테스트로 확인한다.

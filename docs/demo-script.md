# Focusday v1.4 3분 시연

[공개 앱](https://gsj118.github.io/focusday/) 또는 `pnpm build` → `pnpm preview`의 production을 격리/새 브라우저에서 시연한다. 실제 개인 데이터가 있는 브라우저를 초기화하지 않는다. 아래 동작은 자동화 시나리오에서 실제 실행했고, 이 시간표는 **발표 구성**이지 측정한 사람 과업 시간이 아니다.

| --------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |

첫 완료를 이미 처리한 시연 context에서는 같은 날 소급 격려가 나오지 않는 것이 정상이다. 새 격리 context의 새 실제 사용자 항목을 사용한다. 예시 완료로 격려를 시연하지 않는다. 내 문장/문구 끄기는 차분한 격려와 독립이며 격려 자체를 끌 수 있다.

키보드 시연: N 입력→Enter→Tab 제목 편집→Escape 초안 취소→Space 완료→Tab 성취 summary→undo. 입력/모달에서 N·/ 단축키는 차단된다. UndoToast는8초·hover/키보드 focus pause다. OS IME/native 확대/스크린 리더 조작을 검증 완료로 설명하지 않는다.

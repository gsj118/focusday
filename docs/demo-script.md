# Focusday v1.5 자동화 시연

[자동화 체험 바로 열기](https://gsj118.github.io/focusday/?demo=1). 설치·회원가입 없이 오늘 날짜에 맞춘 예시 5개로 시작한다. 개인 데이터는 읽거나 쓰지 않으며, 새로고침으로 체험만 초기화한다. 아래 순서는 발표 구성이지 측정한 사용자 과업 시간이 아니다.

1. **문제 소개:** 할 일을 기록하려다 목록 정리부터 번거로워지는 사람을 위한 앱이다. 입력 → 오늘 정리 → 다음 행동을 연결한다.
2. **추천 이유 확인:** `지금 할 하나`의 오늘 기한, 직접 고른 일, 이전 미완료 같은 실제 근거를 보여준다. 기본 3개이며 기한·직접 선택은 분량을 넘어도 유지한다.
3. **실행 흐름:** `이것부터 시작` → `이 일 완료하기`. 오늘 마친 일이 늘고 다음 후보가 준비된다. 시작 버튼을 다시 누르기 전에는 자동으로 시작하지 않는다. 실행 취소도 확인한다.
4. **입력 자동화:** `내일 발표 자료 제출 #학교 !높음`을 입력한다. 미리보기의 제목·기한·분류·우선순위를 설명하고 Enter로 등록한다. `전체 할 일`에서 확인한다.
5. **여러 줄과 결정권:** 두 줄을 한 번에 붙여 넣는다. 날짜·분류 인식을 끄면 원문으로 저장한다. 자동 계획을 끄면 수동 모드로 사용할 수 있다.
6. **기존 기능:** 제목 편집의 빠른 날짜, 검색, 오늘 마친 일, 문구 설정, JSON 백업·복원 미리보기를 보여준다. 체험에서 내려받은 백업은 demo 이름을 가진다.
7. **개인 사용:** `내 할 일 사용하기`는 원래 개인 목록으로 돌아간다. 실제 개인 데이터가 있는 브라우저에서는 체험 기록을 복원하거나 목록을 초기화하지 않는다.
8. **과제 설명:** AI는 개발·검토·테스트에 활용했다. 앱은 규칙 기반 자동화이며 AI API를 호출하지 않는다. 실제 검증 결과와 공개 배포 근거를 문서에서 보여준다.

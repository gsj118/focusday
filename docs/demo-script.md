# 2~3분 시연

[공개 Focusday](https://gsj118.github.io/focusday/)에서 바로 시연할 수 있다. 로컬은 Node 24 / pnpm 11.19.0에서 `pnpm install --frozen-lockfile`, `pnpm build`, `pnpm preview` 후 `http://127.0.0.1:4173`을 연다. 예시 데이터는 선택적으로 추가하며 기존 개인 데이터가 있는 브라우저는 초기화하지 않는다.

| 시간      | 행동                                                 | 설명                                                                      |
| --------- | ---------------------------------------------------- | ------------------------------------------------------------------------- |
| 0:00–0:20 | 오늘 화면 소개                                       | “계정 없이 기록하고 오늘 할 일에 집중하는 Focusday입니다.”                |
| 0:20–0:40 | ‘발표 자료 확인’ 입력 → Enter                        | 제목만으로 생성·저장. 오늘에서 만든 항목은 오늘에 집중.                   |
| 0:40–1:00 | 전체 → ‘자료 출처 정리’ 입력 → 오늘에 추가           | 전체는 수집, 오늘은 실행. 생성 뒤 추가해도 기한을 바꾸지 않음.            |
| 1:00–1:20 | 제목 클릭 → 내일 기한 선택 → 오늘에 집중 체크 → 저장 | “오늘 미리 할 일과 실제 기한을 별개로 관리합니다.”                        |
| 1:20–1:40 | 체크박스로 완료 → 실행 취소 → 다시 완료 → 완료 목록  | 실수 복구와 완료 영역에서의 미완료 복원. 삭제는 편집기의 보조 행동.       |
| 1:40–2:00 | 제목·분류 수정 → 저장 → 새로고침                     | 수정 유지와 저장 성공 표시. “서버 백업은 없고 이 브라우저에 저장됩니다.”  |
| 2:00–2:20 | Chrome responsive 390×844 → 제목 클릭                | 하단 오늘/전체 탐색과 bottom sheet. 실제 스마트폰 테스트와 구분.          |
| 2:20–2:50 | README → 설계 결정·AI 활용·검증 기록                 | 리서치 가설, 실제 테스트, 발견 후 수정한 포커스 결함, 실제 커밋을 보여줌. |

키보드 시연은 N → 입력 Enter → Tab으로 체크박스/제목 이동 → 제목 Enter → 편집 저장 → Space 완료 → Tab으로 실행 취소를 수행한다. Escape는 편집 초안을 버린다. 실행 취소는 최근 한 건, 8초이며 hover/포커스 동안 만료가 멈춘다.

[GitHub README](https://github.com/gsj118/focusday)에서 공개 시연 링크, 실제 데스크톱/모바일 화면, 설계 결정·AI 활용·검증 문서와 작업별 커밋을 확인할 수 있다. 공개 사이트와 로컬 사이트의 할 일은 각각의 브라우저 origin에 저장된다.
